# Dashboard — Tiempo Real

La vista `Dashboard` usa un Flex Repeater. Cada máquina es una instancia de la vista `Card`.

Importa solo `TiempoReal-Perspective.zip` (no el ZIP de todo el repositorio).

1. Clic derecho en el proyecto → Import.
2. Marca las vistas **Dashboard** y **Card**. Sobrescribe si pregunta.
3. No marques Page Configuration si el proyecto ya tiene páginas.
4. Abre Perspective → Views → Dashboard.

Si las tarjetas salen vacías, falta la vista Card.
